# PodGraph - ポッドキャスター＆番組 共演相関図

ポッドキャスター同士や番組間のレギュラー・ゲスト共演関係をインタラクティブなネットワークグラフで可視化するWebアプリケーションです。

## 主な機能
- **2つのグラフ表示モード切替**:
  - **👤 人物モード（デフォルト）**: ポッドキャスターをノードとして表示。同じ番組のメインMC同士は「太い実線」、ゲスト共演は「点線・回数に応じた実線」で接続。
  - **🎙️ 番組モード**: ポッドキャスト番組をノードとして表示。MC兼任番組や、MCが他番組にゲスト出演した関係を線で接続。
- **1ページ完結型ポップアップUI**:
  - ノード（人物・番組）やエッジ（線）をクリックすると画面右側に詳細ドロワーが開き、**メイン出演番組一覧**・**ゲスト出演エピソード一覧**・**Spotify / Pocket Casts の再生リンク**を表示。
  - ポップアップ内の共演者や番組をクリックすると、背後のグラフが該当ノードにスムーズにフォーカス移動。
- **インクリメンタル検索 & タレコミ連携**:
  - 名前（別名含む）・番組名からのリアルタイム検索と、GitHub Issue テンプレートを利用した共演情報のタレコミ起票に対応。
- **Spotify Web API 半自動データ取得 CLI**:
  - 番組のエピソード一覧を自動取得し、登録済みポッドキャスター名（別名含む）の辞書照合＋キーワード抽出でゲスト出演回候補を自動リストアップ。

## セットアップと起動

```bash
# パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# 単体テストの実行
npm run test

# 本番用ビルドの生成
npm run build
```

## 半自動データ取得スクリプトの使い方

1. `.env.example` を参考に、環境変数 `SPOTIFY_CLIENT_ID` と `SPOTIFY_CLIENT_SECRET` を設定します。
2. `src/data/podcasters.json` と `src/data/podcasts.json` にポッドキャスター・番組（`spotifyShowId` 含む）を登録します。
3. 以下のコマンドでエピソード一覧の取得とゲスト候補抽出を実行します：
   ```bash
   npm run sync:spotify
   ```
4. `src/data/candidates.json` に出力された候補を確認し、`approved: true` の候補を以下のコマンドで `src/data/episodes.json` に反映します：
   ```bash
   npm run approve:candidates
   ```
